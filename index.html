⚙️ One-time Firebase setup required 1. Go to console.firebase.google.com → Create a project (free)
2. Click Realtime Database → Create database → choose test mode
3. Go to Project Settings → Your apps → Add web app → copy the config
4. Replace the FIREBASE_CONFIG object near the top of this HTML file with your config
5. That's it — real multiplayer works instantly on GitHub Pages!
